🚀 Installation & Usage Guide

📦 Step 1 — Download the ZIP File

Download the latest ".zip" file of the project.

«[!IMPORTANT]
Do NOT extract the ZIP file if your browser supports direct ZIP extension installation.
You can select the downloaded ZIP file directly from the browser's extension manager.»

The previous Node.js installation commands are not required.

---

💻 PC Users — Chrome / Chromium

For Chrome and most Chromium-based desktop browsers:

1. Download the latest ".zip" file.
2. Open your browser's Extensions page.
3. Enable Developer Mode.
4. Click Load unpacked.
5. Select the extension folder.

«[!NOTE]
Desktop Chromium browsers generally require the extension files to be in an extracted folder when using Load unpacked. If the browser provides a direct ZIP installation option, you can select the ZIP file directly instead.»

6. Open supported websites such as Discord Web or Messenger Web.
7. Make sure the extension is enabled.
8. The VOICE LOUDER panel should appear automatically when the extension is compatible with the website.

---

📱 Android / iOS Users

You can use a mobile browser that supports browser extensions.

Examples include browsers such as Kiwi Browser or Quetta Browser, depending on the platform and browser version.

📦 Direct ZIP Installation

If your browser supports installing extensions directly from a ".zip" file:

1. Download the latest ".zip" file.
2. Open the browser's Extensions section.
3. Choose the option to install/import an extension.
4. Select the downloaded ZIP file.
5. Enable VOICE LOUDER.
6. Open a supported web service such as Discord Web or Messenger Web.
7. The panel should appear automatically if the browser and website are compatible.

«[!TIP]
ZIP extract করার দরকার নেই when the browser supports direct ZIP installation.»

📂 If Direct ZIP Installation Is Not Supported

Some browsers do not allow ZIP files to be installed directly.

In that case:

1. Extract the ZIP file using your device's file manager.
2. Open the browser's extension manager.
3. Import/load the extracted extension folder if the browser supports it.
4. Enable the extension.
5. Open the supported website.

---

⚠️ Important

- Make sure VOICE LOUDER is enabled before opening the supported website.
- Extension support varies between browsers and browser versions.
- Some websites may change their audio/video implementation, which can affect compatibility.
- Mobile browsers may have different extension limitations compared with desktop browsers.
- The extension does not require Node.js for normal installation or usage.
- Only use the extension on accounts and websites you are authorized to access.
