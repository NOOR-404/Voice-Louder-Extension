🚀 Installation & Usage Guide

📦 Step 1 — Download the ZIP File

First, download the latest ".zip" file of the project and extract it on your device.

«Note: The previous Node.js installation commands are not required.»

💻 PC Users

Chrome / Chromium-Based Browsers

1. Download the latest ".zip" file.
2. Open your browser.
3. Go to the Extensions page.
4. Enable Developer Mode.
5. If your browser supports direct ZIP installation, select/import the downloaded ".zip" file directly.
6. If the browser only provides Load unpacked, extract the ZIP first and select the extracted extension folder.
7. Make sure VOICE LOUDER is enabled.
8. Open a supported website such as Discord Web or Messenger Web.
9. The VOICE LOUDER panel should appear automatically when supported.

📱 Android / iOS Users

You can use a mobile browser that supports browser extensions.

Examples include browsers such as Kiwi Browser or Quetta Browser, depending on the platform and browser version.

📦 Direct ZIP Installation

If your browser supports installing extensions directly from a ".zip" file:

1. Download the latest ".zip" file.
2. Open the browser's Extensions section.
3. Choose the option to install/import an extension.
4. Select the downloaded ZIP file.
5. Enable VOICE LOUDER.
6. Open a supported web service such as Discord Web or Messenger Web.
7. The panel should appear automatically if the browser and website are compatible.

⚠️ Important

- Make sure the extension is enabled before opening the supported website.
- Browser extension support can vary between browsers and versions.
- Only use the extension on accounts and websites you are authorized to access.
